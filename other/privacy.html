Política de Privacidad

Última actualización: 2 de octubre de 2026

1. Información general

Esta aplicación es una herramienta personal destinada a gestionar y publicar contenido en una cuenta de Instagram mediante las APIs oficiales de Meta/Instagram.

2. Información que utiliza la aplicación

La aplicación puede acceder a información básica de la cuenta de Instagram autorizada y a los permisos necesarios para publicar contenido en dicha cuenta.

La aplicación no recopila ni almacena información personal de terceros.

3. Uso de la información

La información obtenida mediante la API de Instagram se utiliza exclusivamente para autenticar la cuenta y gestionar la publicación de contenido en Instagram.

4. Almacenamiento y seguridad

Los tokens de acceso y cualquier otra información necesaria para utilizar la API se almacenan de forma segura y no se venden ni se proporcionan a terceros.

5. Servicios de terceros

La aplicación utiliza las APIs proporcionadas por Meta Platforms, Inc. para interactuar con Instagram. El uso de Instagram también está sujeto a las políticas y condiciones de Meta.
